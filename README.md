# 坦克大战 · 铁鹰防线

一款 Godot 4.x 单人俯视角坦克防守游戏。灵感来自经典 8 位坦克游戏的规则与节奏；代码、地图、坦克/地形像素图形及合成音效均为本项目原创，不含原游戏 ROM、贴图或音乐。

## 开始游戏

1. 安装 **Godot 4.3 或更新的 4.x**（实际验证版本：4.7.2）。
2. 在项目管理器导入 `project.godot`，按 **F5** 运行主场景。
3. 按 **Enter** 或点击「开始作战」。无需外部服务或联网素材。

也可命令行运行：

```sh
godot --path .
```

### 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 四向移动，炮口随车身方向 |
| 空格（可按住） | 开火，最多同时存在 2 发玩家炮弹 |
| P / Esc | 暂停 / 继续；窗口失焦也会暂停 |
| R | 重新开始本关 |
| M | 切换音效 |
| Enter | 开始 / 结算后再次出击 |

## 规则

- 守住底部中央的铁鹰基地，击破全部 **20 辆**敌军即获胜；同屏最多 4 辆敌军。
- 玩家有 **3 条命**（含初始战车）。阵亡后自动复活，获得 3 秒护盾；敌军占住出生位置时会等待安全位置。
- 基地被敌方炮弹命中，或生命耗尽即失败。**玩家炮弹不会误伤基地；同阵营炮弹不伤友军。**
- 橙色砖墙分成半块，可被炮弹逐层破坏；银色钢墙无法破坏。
- 蓝色水域挡坦克、不挡炮弹；绿色草丛遮住坦克、不阻挡行动或炮弹。
- 敌我炮弹相撞会抵消。刚生成的敌军带短暂保护与出生提示。
- 每击破 5 / 10 / 15 辆敌军，会在基地旁通道出现限时护盾补给；拾取获得 8 秒护盾和 250 分。

| 敌军 | 特征 | 击破分数 |
| --- | --- | --- |
| 灰色普通型 | 均衡推进 | 100 |
| 橙色侦察型 | 高速，靠近时追击玩家 | 200 |
| 蓝色火炮型 | 长炮管，弹速快、射击间隔短 | 300 |
| 绿色装甲型 | 慢速，需命中 3 次；车尾标记显示装甲 | 400 |

敌军使用带砖墙成本的网格寻路，向基地推进、遇砖开火，并在玩家进入同轴射程时转向攻击。保留经典单关街机玩法，没有联机、关卡编辑器或多关战役。

## 项目结构

- `scripts/battle.gd`：独立战斗模型、寻路、微步炮弹碰撞、关卡和状态机。
- `scripts/main.gd`：程序化像素绘图、中文界面、输入、合成音效。
- `scenes/main.tscn`：入口场景。
- `assets/fonts/`：本地化字体子集及许可。
- `tests/`：无需 GUI 的回归测试、原生渲染检查。
- `docs/QA.md`：覆盖范围与验证限制。

## 回归测试

```sh
GODOT_BIN=/path/to/godot tests/run_tests.sh
```

运行器为受限环境隔离 XDG 缓存，并检查完成标记与错误输出，而不仅依赖 Godot 的退出码。
