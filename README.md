# 坦克大战 · 铁鹰防线

**Godot 4.x 原生 2–8 人红蓝团队联机对抗**。没有 AI、电脑敌人或同机假联机；房主也作为玩家参战。保留原创经典像素坦克、半砖破坏、钢墙、水域、草丛和炮弹对消。

## 运行与联机

1. 用 **Godot 4.3 或更新的 4.x** 导入 `project.godot`，按 **F5**；也可 `godot --path .`。
2. 输入昵称。房主点击「创建房间」，默认 **UDP 7777**（可改为 1024–65535 的端口）。
3. 朋友输入房主的 **IP 地址和相同端口**，点击「加入房间」。同一台电脑测试用 `127.0.0.1`；局域网用房主的局域网 IP。支持地址栏填写 IPv6 地址（如 `::1`，网络须可达）。
4. 选择红队 / 蓝队并准备。**2–8 人、每队最多 4 人、两队人数差不超过 1、两队均有人、所有客户端准备**时，房主才能开始。3 / 5 / 7 人也可玩；房主自动准备。

### 网络边界

- 使用 **ENet / UDP、房主权威模拟**；客户端只提交自己的移动方向、开火状态和输入序号。坐标、子弹、地形、伤害、基地 HP、护盾、复活与击破统计均由房主决定并复制。
- **互联网直连需要房主 UDP 端口可达**，可能需要自行配置路由器端口转发与防火墙许可。项目不自动修改任何网络/安全设置，**不提供 NAT 穿透、匹配服务器、账号或中继服务**。运营商 CGNAT 下仅转发家用路由器端口可能无效。
- 房主离开 / 连接丢失会结束房间，并给出原因返回入口；不支持房主迁移。比赛期间不接受新玩家，需等房主返回大厅再加入。
- 游戏不提供加密、身份认证或防 DDoS 服务。请与可信朋友联机；输入校验/限速防止客户端直接伪造战斗状态，但无法防止房主作弊。
- 目前客户端按 20 Hz 权威快照显示；无客户端预测、回滚或延迟补偿。局域网/低延迟直连体验更佳。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 四向移动，炮口随车身方向 |
| 空格（可按住） | 开火；每人最多同时存在 2 发炮弹 |
| Esc | 本地菜单 / 继续；**不会暂停其他玩家或房主模拟** |
| M | 本地音效开关 |

菜单打开、窗口失焦或确认框显示时，自己的移动/开火输入停止。房主返回大厅或玩家离开均需确认；取消操作保持连接。房主可在结算后返回大厅再次组队、准备、开战。

## 对抗规则

- 红队在上方、蓝队在下方；地图上下/左右对称，双方出生区与掩体布局相同。
- **摧毁对方基地获胜**。每个基地 **5 HP**，每次有效扣血后 **1 秒无敌**，显示 HP 条与护盾闪烁；同一模拟帧双方基地同时被毁为平局。
- 玩家一发有效敌弹即阵亡，**无限复活**：等待 **2 秒**后重生，并获得 **2 秒无敌护盾**。出生位置被占时选择空闲位置，全部被占时等待，不重叠生成。没有剩余生命限制。
- **不误伤队友和己方基地**。对方炮弹命中无敌玩家/基地会被挡下但不扣血。子弹彼此碰撞时，只有敌对阵营炮弹相互抵消。
- 砖墙按半层破坏；钢墙不可破坏；水域挡坦克但不挡子弹；草丛遮挡坦克但不阻挡移动和子弹。双方基地周围砖掩体都可被打穿。
- 玩家断线立即移除其坦克、炮弹与待复活状态；若某队无人，另一队获胜。击破/阵亡统计在每局重新开始时清零。

### 可调参数

`scripts/battle.gd` 集中定义 60 Hz 模拟参数：

| 常量 | 默认 |
| --- | --- |
| `RESPAWN_DELAY` / `RESPAWN_TICKS` | 2 秒 / 120 tick |
| `RESPAWN_SHIELD` / `SHIELD_TICKS` | 2 秒 / 120 tick |
| `BASE_HP` | 5 |
| `BASE_INVULNERABILITY` / `BASE_SHIELD_TICKS` | 1 秒 / 60 tick |
| `FIRE_TICKS` / `MAX_BULLETS` | 17 tick / 2 发 |
| `PLAYER_SPEED` / `BULLET_SPEED` | 106 / 294 像素每秒 |

tick 常量由秒数与 `TICK_RATE` 自动向上取整；修改秒数即可同步更新。网络房间常量与输入限速在 `scripts/network.gd`。

## 项目结构

- `scripts/battle.gd`：无渲染依赖的确定性团队战斗模型；无 AI。
- `scripts/network.gd`：ENet 房间、准备/队伍校验、房主权威输入/快照、断线与重开。
- `scripts/main.gd`：原生界面、中文控件、程序化像素绘图、输入与合成音效。
- `tests/test_battle.gd` / `tests/run_tests.sh`：确定性规则回归。
- `tests/network_peer.gd` / `tests/run_network_tests.py`：真实多进程 ENet 回归（不是模拟网络）。
- `tests/native_capture.gd` / `tests/native_peer.gd`：已有桌面上的真实双进程原生渲染/交互检查。
- `docs/QA.md`：实际验证覆盖与限制。

## 回归测试

```sh
GODOT_BIN=/path/to/godot tests/run_tests.sh
GODOT_BIN=/path/to/godot python3 tests/run_network_tests.py
```

原生截图需要现有桌面显示器，不能用 `--headless`：

```sh
TANK_CAPTURE_DIR=/absolute/writable/output godot --path . --script res://tests/native_capture.gd
```

测试脚本的预设输入仅用于测试人的操作，不会成为游戏里的 AI。测试输出/截图不打包进源码。
